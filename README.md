## What Is This?

Seldon's Game TNG is a modernized and considerably expanded recreation of Mike Singleton's 1985 ZX Spectrum game, "Seldon's Game." It simulates the rise and fall of galactic empires according to deterministic rules inspired by Asimov's psychohistory.

**Current Version:** v0.9.0

## Getting Started

If you want to run the simulation yourself:

1.  **Navigate to the game directory:**
    ```bash
    cd seldon-game
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Run the development server:**
    ```bash
    npm run dev
    ```
