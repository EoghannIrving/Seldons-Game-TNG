# Visual Indicators Guide
## Seldon's Game TNG - Galaxy Map Legend

**Last Updated:** 2026-02-17
**Purpose:** Reference guide for all visual indicators displayed on the galaxy map

---

## **STAR RINGS & HALOS**

### **Cyan/Turquoise Rings**
- **Pulsing cyan ring** → Currently **selected star** (click to select)
- **Outer cyan ring with glow** → **Hovered star** (mouse over)
- **Cyan highlight ring** → **Filtered/search result** (matches your current filter/search)

### **Gold Rings & Glow**
- **Gold ring + gold radial glow** → **Foundation Tier Star** (psychohistorically significant)
- Tooltip shows: ⭐ Foundation

### **Star-Colored Rings**
- **Faint pulsing ring (star's own color)** → **Independent Major Power**
- Only appears for Major tier stars that rule themselves
- Indicates galactic-scale influence

### **Dashed/Broken Rings** (rotating)
- **Broken ring slowly rotating** → **Crumbling Empire**
- Indicates high decadence (>0.6) OR low vitality (<0.2)
- Tooltip shows: ⚠️ Low Vitality OR 💔 Decadent

## **CRISIS INDICATORS** (Colored Shapes)

Active Seldon Crises create colored shapes around affected stars:

### **Shapes:**
- **Circle/Ring** → Default crisis indicator
- **Star shape** (rotating spikes) → Special crisis type
- **Diamond** (rotated square) → Alternative crisis type

### **Colors by Severity:**
- **Bright red** → Critical severity (>0.7)
- **Orange-red** → High severity (0.4-0.7)
- **Yellow-orange** → Moderate severity (<0.4)

### **Crisis Types:**
Tooltip shows specific crisis type with icon:
- 🔬 **Technological Crisis** → Sudden tech jump by rival
- 💰 **Economic Crisis** → Trade collapse or economic disruption
- ⛪ **Religious Crisis** → Ideological/religious movement spreading
- 👑 **Succession Crisis** → Civil war risk, disputed throne
- 👽 **External Crisis** → "The Mule" equivalent, unpredictable threat

### **Event Symbols** (in recent history):
- ⚠️ Generic crisis event
- ✊ Rebellion
- ☄️ Plague
- ⚔️ War/Conquest
- 🗽 Independence
- 👑 Leader event

## **LINES BETWEEN STARS**

### **Blue Arrows** (ruler arrows)
- Show **vassal/subject relationships**
- Arrow points FROM subject TO capital/ruler
- Enable via View Options → "Ruler Arrows"

### **Yellow-Gold Dashed Lines** (animated)
- **Trade routes** between partners
- Dash animation flows to show active commerce
- Enable via View Options → "Trade Routes"

### **Green Lines**
- **Alliances** between independent stars
- Solid or dashed depending on theme
- Enable via View Options → "Alliances"

### **Red Pulsing Lines**
- **Active wars** between stars
- Wide beam with pulsing intensity
- Enable via View Options → "Wars"

---

## **STAR SIZE & APPEARANCE**

### **Size Variations:**
- **Large stars** → Major Tier (galactic powers)
- **Medium stars** → Regional Tier
- **Small stars** → Minor Tier

### **Color Meaning:**
Star color indicates **star type** (not political status):
- **Blue** → Blue Giant
- **Yellow** → Yellow Dwarf
- **Red** → Red Dwarf or Red Giant
- **Pink/Magenta** → Binary System
- **White** → White Dwarf

### **Desaturation:**
- **Faded/grey colors** → Low vitality star
- Vitality < 0.6 causes progressive desaturation
- Indicates aging or declining empire

## **SPECIAL LABELS**

### **Crown Icon** 👑
- Appears before star name
- Indicates **Genius Leader** currently ruling
- Tooltip shows: 👑 in recent events

### **Capital Status**
- Not directly shown on map (only in tooltip)
- Tooltip shows: 👑 Capital (X subjects)
- Appears when star is independent AND has subjects

## **TOOLTIP INFORMATION**

Hovering over any star shows:

### **Core Stats:**
- Name & Star Type
- Epoch (👑 Imperial / 🤝 Communal)
- Strength, Power, Population, Tech
- Ruler status

### **Visual Status Indicators:**
- ⭐ Foundation (gold ring)
- ⚠️ Low Vitality (broken ring)
- 💔 Decadent (broken ring)
- 👑 Capital (has subjects)
- 🔴 Active Crisis (colored shapes)

### **Traits:** (top 3)
Shows personality/characteristics with icons

### **Recent Events:** (last 3)
Shows recent historical events with:
- Icon indicating event type
- Description of what happened

---

## **DETAIL VIEW** (Click Star)

Provides 5 tabs of information:
1. **Entry** - Encyclopedia-style overview
2. **Narrative** - AI-generated story
3. **Events** - Full historical event log
4. **Relations** - Diplomatic relationships
5. **Lineage** - Dynasty/succession info

Mini-map in corner shows:
- **Cyan dot** → Selected star
- **Blue dots** → Subjects of selected star
- **Yellow dots** → Ruler of selected star (if vassal)

---

## **VIEW OPTIONS PANEL**

Toggle visibility for:
- Grid overlay
- Ruler arrows (blue)
- Trade routes (yellow)
- Alliances (green)
- Wars (red)

**Tip:** Collapse this panel to hide specific relationship types and reduce visual clutter.
